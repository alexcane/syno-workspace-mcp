Works like the connectors you already know

Your assistant gets the same kind of access to your files as with a cloud connector. The difference is where the files live and who runs the bridge.

What your assistant can do

26 tools for Synology Drive and Synology Spreadsheet, available to any AI assistant that speaks the Model Context Protocol (MCP).

⌕

Find files

List folders, search by name or extension across your team folders, read file details.

⇅

Organize Drive

Upload, download, create folders, move, rename, add labels and create sharing links.

▦

Read spreadsheets

Read sheets with formula results, styles and metadata, or export a whole spreadsheet.

✎

Edit spreadsheets

Create spreadsheets and sheets, write cells, append rows, apply styles.

Private and careful by design

The server runs on your NAS and talks only to your own DSM. File contents reach your assistant only when a tool returns them.

  • No third-party service. No account to create, no telemetry.
  • Least privilege. The server uses a dedicated DSM account that only gets the team folders you choose.
  • No surprise changes. Tools that overwrite, rename or delete do nothing without an explicit confirmation.
  • HTTPS only. Served behind the DSM reverse proxy, with your own certificate.

Get started in three steps

  1. Install it on the NAS

    Follow the Container Manager guide, entirely in the DSM web interface.

  2. Run the setup page

    It prepares the DSM account and the team folder, then generates the access token.

  3. Connect your assistant

    One-click extension for Claude Desktop, one command for Claude Code, or the server address and token for any MCP client that supports remote servers with a custom header. Client setup

Requirements

DSM 7.2 or later with Container Manager, Synology Drive Server and Synology Office, and an HTTPS address for the NAS with a valid certificate.
