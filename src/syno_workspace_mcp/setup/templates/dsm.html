Option A: prepare a new account (recommended)

DSM only lets its own web interface create accounts, so start there:

  1. In DSM, open Control Panel → User & Group → User → Create.
  2. Name it {{ default_account }}, give it a strong password, tick Disallow the user to change account password, and leave every other page as is.

This page then uses an administrator account once to create the folder Claude will work in (if needed), give the new account read/write access to it, allow Synology Drive, and test the login. The administrator credentials are not stored.
